## 🚀 Quick Start

### Installation (5 minutes)
```bash

npm install
npm run dev
```

### Access
Open your browser to: **`http://localhost:3002`**

- ✅ Homepage with hero section

## 🐛 Troubleshooting

### Common Issues
1. **Blank screen?** Check browser console (F12) for errors
2. **Port in use?** Dev server auto-selects next port (3002)
3. **Styling issues?** Restart dev server to rebuild Tailwind
4. **Missing images?** Check src/assets folder

**More help:** [See QUICKSTART.md](./QUICKSTART.md#-debugging-tips)
