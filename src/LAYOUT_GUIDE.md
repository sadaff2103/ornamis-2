# ORNAMIS Layout Guide

## Overview

ORNAMIS now features two distinct layout options for the home page with improved loading animations:

### 1. **Full Layout** (Default)
- Rich, immersive experience with full header and footer
- Large hero section with detailed product showcases
- Comprehensive navigation and feature sections
- Best for desktop/tablet viewing
- Full-featured carousel and product grids

### 2. **Minimal Layout** (Lightweight)
- Optimized for fast loading and mobile-first experience
- Clean white background with minimal elements
- Compact carousel banner (180px height)
- Simple category grid with emoji icons
- **NEW: Featured Stores Section** with:
  - Tanishq
  - Giva
  - Malabar
- Bottom navigation bar with icons (Home, Categories, Cart, Profile)
- Flat design with minimal shadows and gradients
- Export-friendly and optimized for prototypes

## Performance Improvements

### Loading Page - ⚡ Fast & Smooth
- **Refined beige gradient background** - Soft, non-overpowering palette
- **Optimized title size** - Reduced from 3xl to 2xl for better visibility
- **Improved contrast** - Dark brown text (#2c1810) with subtle text shadow
- **Faster animations** - 0.3-0.4s transitions (previously 0.8s)
- **Quick shimmer effect** - 1s rotation with pulsing center dot
- **Enhanced hierarchy** - Clear spacing and centered layout
- Background: `linear-gradient(135deg, #faf8f5 0%, #f0ebe3 50%, #e8dfd5 100%)`

### Intro Screen - ⚡ Faster Transitions
- **Reduced slide duration** - 1.8s per slide (previously 2.5s)
- **Faster initial load** - Total intro time: ~5.8s (previously ~8s)
- **Smoother animations** - 0.5s fade transitions
- **Better readability** - Smaller title sizes (3xl-5xl responsive, previously 5xl-7xl)
- **Improved contrast** - Dark text with subtle shadows on beige gradient
- **Quick exit** - 300ms completion delay (previously 500ms)

## Features

### Stores Section (Minimal Layout Only)
Located between categories and trending products, featuring:
- Three brand cards with images and ratings
- Clean card layout with subtle borders
- Star ratings display
- Click to navigate to collections

### Bottom Navigation (Minimal Layout Only)
- Fixed bottom bar for easy mobile access
- Icons for: Home, Categories, Cart, Profile
- Cart badge shows item count
- Smooth transitions and hover effects

## Toggle Between Layouts

A floating toggle button appears on the home page (bottom right) allowing users to:
- Switch from Full to Minimal layout
- Switch from Minimal to Full layout
- Icon changes based on current layout

## Design Principles (Minimal Layout)

✅ **Lightweight**
- Minimal gradients and shadows
- Flat icons and simple shapes
- Optimized image loading

✅ **Fast Rendering**
- Reduced visual complexity
- Simplified animations
- Clean spacing and hierarchy

✅ **Mobile-First**
- Bottom navigation for thumb-friendly access
- Compact components (180px carousel vs 500px hero)
- Responsive grid layouts

✅ **Export-Friendly**
- Simple, clean elements
- Consistent color palette (white, gray-900, gray-50)
- Easy to replicate in design tools

## Color Palette (Minimal)

- **Background**: White (#FFFFFF)
- **Primary Text**: Gray-900 (#111827)
- **Secondary Text**: Gray-600 (#4B5563)
- **Accents**: Gray-100 (#F3F4F6), Gray-50 (#F9FAFB)
- **Brand**: Cinzel font for logo

## Usage

The layout automatically switches when you click the toggle button on the home page. The minimal layout is perfect for:
- Mobile app prototypes
- Fast-loading landing pages
- Lightweight demos
- Export to Figma or other design tools
- Performance testing

The full layout is ideal for:
- Desktop experiences
- Rich product showcases
- Full-featured e-commerce
- Brand storytelling
